# Contributing to Halcyon

Language: [中文](./CONTRIBUTING-zh.md) [English](./CONTRIBUTING.md)

Thank you for your interest in the Halcyon operating system! Before submitting the code, please take a few minutes to read the following guidelines.

## License Description (Important)

Halcyon adopts a dual license mode:
| Directory | License |
| --------- | ------  |
| api/*     | MIT     |
| Others    | AGPLv3  |

When submitting a PR, please indicate in the description which license your code is applicable to.

##.How to contribute

### Report issues

- Search for existing issues first to avoid duplication
- Provide as much as possible: reproducing steps, expected behavior, actual behavior, and operating environment

### Submit code

1. Fork's own warehouse (Gitee: [![Fork me on Gitee](https://gitee.com/smoa-new/halcyon/widgets/widget_5.svg)](https://gitee.com/smoa-new/halcyon))
2. Create a branch See [BRANCH.md](./BRANCH.md)
3. Submit changes
4. Push to your Fork
5. Submit a Pull Request

### Pull Request Request Request

- A PR only does one thing
- The PR title is concise and to the point
- Explain in the description what changes were made and why they were made
- If dual license is involved, indicate the code ownership
