Halcyon is currently **pre-release** and has not yet reached its first stable version.

The project is under active development. APIs, file formats (including `.vexe`), system behavior, and internal architecture are subject to change without notice.

**Do not use this software in any production environment or for critical purposes.**

- Kernel: not yet implemented
- Halcyon32 API: under design
- `.com` compatibility layer: planned
- `.vexe` executable format: specification in progress
