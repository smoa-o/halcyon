# Troubleshooting

## Build fails
- Check toolchain version
- Ensure NASM is installed and in PATH

## OS doesn't boot
- Verify image is written correctly
- Check VM settings (should be x86, 32-bit)

## COM file won't run
- Ensure it's a valid DOS-format .com file
- Check memory limits (64KB max)
